# Telegram Mood Tracker

Мой первый проект на Python и aiogram. Телеграм-бот для отслеживания ежедневного настроения.

## Стек технологий
* Python 3
* Aiogram 3
* Встроенная библиотека "collections" (в планах переход на SQLite)

## Функционал
* Команда "/start" и главное меню.
* Возможность отметить настроение по шкале от 0 до 10.
* Просмотр последней записи.
* Защита от ввода текста вместо чисел.

## Как запустить локально
1. Склонируйте репозиторий.
2. Установите зависимости: "pip install aiogram"
3. Создайте файл "config.py" и добавьте туда: "TOKEN = "ваш_токен_от_BotFather"
4. Запустите бота: "python main.py"
